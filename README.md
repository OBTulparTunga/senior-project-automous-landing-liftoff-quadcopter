# Development and Implementation of a Custom Quadcopter for Autonomous Target Detection and Landing

Senior Project, Özyeğin University, Spring 2025-26

I designed an F450 quadrotor drone capable of fully autonomous flight with real-time manual override, and of landing autonomously on an ArUco-marked area using image processing. It runs on integrated ArduPilot, OpenCV and DroneKit software. I assembled the drone, calibrated the system, and wrote the vision processing code as well as the takeoff and landing logic that responds to what the camera detects.

I put the presentation for easy demonstration and the long report that have all the details for further study. 

The used codes are on the report.
